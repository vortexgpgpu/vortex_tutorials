# Vortex Workshop and Tutorial at MICRO-59 (November 1, 2026)

For more information about the workshop, please visit our [website](https://vortexgpgpu.github.io/micro2026.html).

You can also find more information about Vortex on our [homepage](https://vortexgpgpu.github.io/).

## Tutorial Assignments

Twelve hands-on assignments for Vortex v3.0, grouped into microarchitecture, debug and
performance tools, programming models, and accelerators and graphics. See the
[exercise index](Exercises/README.md).

## Getting Vortex

### Remote Access
A terminal interface hosted by the [CRNCH Rogues Gallery](https://crnch-rg.cc.gatech.edu/) is provided. [Instructions can be found here](./REMOTE_ACCESS.md).


### Apptainer
See the [Apptainer instructions](./apptainer/README.md) for how to set up the apptainer and run simulation for Vortex.


### Docker (Experimental)
See the [Docker instructions](./docker/README.md) for how to set up a Docker image for Vortex.

### System Set Up Instructions
If you would like to set up Vortex on your own system, [instructions can be found here](https://github.com/vortexgpgpu/vortex/blob/master/docs/install_vortex.md).
